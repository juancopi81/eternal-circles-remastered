Precompute melody sets

Walks MusicVAE's latent space (mel_2bar_small) from seed A to seed B in eight stations for every set in src/music/seeds.js, and prints the result as JSON. Paste it into src/music/sets.js. The walk itself lives in src/music/latent-walk.js; nudging repeated stations is random, so every run gives a slightly different set.

Serve the repo root over HTTP (for example python3 -m http.server) and open /tools/precompute.html.
